📘 คู่มือ HTML เบื้องต้น

เรียนรู้โครงสร้างและคำสั่งพื้นฐานของ HTML อย่างเข้าใจง่าย

📄 โครงสร้างข้อความ

p ใช้เขียนข้อความทั่วไปในเว็บ

b ทำให้ตัวอักษรหนา
strong ก็ทำให้ตัวหนาเช่นกัน (มีความสำคัญมากขึ้น)
i ทำให้ตัวอักษรเอียง
mark ไฮไลต์ข้อความ
small ตัวอักษรเล็กลง
del ขีดฆ่าข้อความ
ins ขีดเส้นใต้ข้อความ
sub ตัวอักษรเล็กลงและอยู่ข้างล่าง
sup ตัวอักษรเล็กลงและอยู่ข้างบน

🔗 การสร้างลิงก์

a ใช้สำหรับเชื่อมโยงไปยังหน้าเว็บอื่น

target="_blank" คือเปิดลิงก์ในแท็บใหม่

👉 คลิกไปที่ ChatGPT

🖼️ การแสดงรูปภาพ

img ใช้แสดงภาพโดยกำหนด URL หรือไฟล์ในเครื่อง

📊 ตาราง (Table)

table ใช้แสดงข้อมูลเป็นแถวและคอลัมน์

📋 รายการ (Lists)

ul คือรายการแบบไม่มีลำดับ (จุดกลม)

  • HTML
  • CSS
  • JavaScript

ol คือรายการแบบมีลำดับ (ตัวเลข)

  1. เริ่มต้น
  2. ฝึกเขียน
  3. สร้างโปรเจกต์
